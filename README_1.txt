РЕДАКТОР НОВОСТЕЙ ДЛЯ WINDOWS
==============================

Состав комплекта:
- news_editor.py — программа на Python/Tkinter.
- start.bat — запуск двойным щелчком.
- build_exe.bat — сборка самостоятельного EXE через PyInstaller.
- УПАКОВАТЬ_В_RAR.bat — упаковка папки в RAR, если установлен WinRAR.
- README.txt — эта инструкция.

Быстрый запуск
--------------
1. Установите Python 3.10 или новее с сайта python.org. Во время установки включите
   пункт "Add Python to PATH".
2. Запустите start.bat.
3. Данные сохраняются автоматически в файле news.db рядом с программой.

Что умеет редактор
------------------
- создавать, изменять и удалять новости;
- хранить заголовок, рубрику, автора, статус, дату, теги, краткое описание и текст;
- искать по заголовку, тексту и тегам;
- фильтровать по статусу;
- открывать предпросмотр;
- импортировать JSON и экспортировать JSON/CSV.

Сборка EXE
----------
Запустите build_exe.bat. Скрипт установит PyInstaller и создаст папку dist с файлом
NewsEditor.exe. EXE можно запускать на Windows без отдельной установки Python.

Упаковка в WinRAR
-----------------
Сначала соберите EXE (необязательно), затем запустите УПАКОВАТЬ_В_RAR.bat.
Он ищет WinRAR.exe в стандартных папках. Если WinRAR не установлен, используйте
ZIP-архив из комплекта или установите WinRAR и повторите запуск.
